
# StudyMate — Academic Command Centre

A modern, dark-themed study management dashboard designed to help students organize their academic life, stay focused, and track their progress.

🔗 **Live Demo:** https://achuth-k.github.io/studymate/

## ✨ Features

- **Dashboard:** View study statistics and academic progress.
- **Study Planner:** Create, manage, and track study tasks.
- **Subject Library:** Add subjects and monitor completion progress.
- **Pomodoro Timer:** Focus sessions, short breaks, and deep-work mode.
- **Exam Tracker:** Keep track of upcoming examinations.
- **Quick Notes:** Save important study notes.
- **Quick Quiz:** Test your knowledge with short quizzes.
- **Responsive Design:** Designed to work on mobile and desktop.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 💻 Getting Started

1. Clone this repository:
   `git clone https://github.com/achuth-k/studymate.git`
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.
